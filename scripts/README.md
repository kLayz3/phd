## Using RDataFrame 
RNTuple data cannot be analysed by traditional interpreter inspections.
One uses the [RDataFrame](https://root.cern.ch/doc/master/group__tutorial__dataframe.html) API.

Example:
Suppose we wish to draw SCI31 sqrt(L*R) QDC value with condition that multiplicity (TDC) is 1:

```
root [0] ROOT::RDataFrame df("h102", "mapdir/PATH.root")
root [1] auto df1 = df.Filter("FRS.sci[2].tdc.size() == 1").Define("qdc0", "FRS.sci[2].qdc[0]").Define("qdc1", "FRS.sci[2].qdc[1]")
root [2] auto df2 = df1.Define("qdc", "std::sqrt(1.0 * qdc0 * qdc1)")
root [3] auto h = df2.Histo1D("qdc")
root [4] h->Draw()
```
Steps [1], [2], [3] can be chained together, but before draw a real object must own the return object of 
`.HistoXD(const char*)` call


`TCutG` objects can be used via the `TCutG::IsInside(double, double) -> bool` predicate. They might not be thread safe,
so one can capture the global `TCutG` pointer and call `TObject::Clone()` on it and stuff in `thread_local std::unique_ptr<TCutG>`


### Cal Step

#### `tpc_draw_track.C`
- File Name
- `{TPC, dl}` pair of the TPC with suspicious delay line
- `max_events`
Will draw TPC tracking through S2, tracked by `_take[N][2]` array specifying which measurements
go into the consideration.

#### `foot_eta_corr.C`
- File Name
- Foot Index
- `{a,b}` cut -> can be left open, will prompt for cut

#### `foot_eta_corr_fit.C`
- File Name
- Foot Index
- `{a,b}` SCI21 cut -> can be left open, will prompt for cut
  - Always taken from SCI21 !

Unlike first macro, this one won't take `{E_Sum, CoG}` but rather the fitted value
for the cluster.
